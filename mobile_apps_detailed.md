## 1. Приложения для судей

### 1.1 ProScore iKeypad

**Разработчик:** Auburn Electronics Group
**Платформы:** iOS (iPad, iPhone)
**Стоимость:** Бесплатное приложение (требует ProScore лицензию v5.1.0+)
**Официальный сайт:** https://www.aegroup.com/proscore/ikeypad.htm

#### Описание

ProScore iKeypad позволяет судьям вводить оценки напрямую с каждого снаряда/предмета, устраняя необходимость в раннерах для переноса карточек к главному судейскому столу.

#### Ключевые возможности

**Гибкость ввода оценок:**
- 1 iKeypad на снаряд с вводом оценок всех судей
- Каждый судья использует собственный iKeypad
- Ввод номера гимнастки или выбор из списка
- Кнопки Scratch и Bingo для ускорения ввода

**Специализированные функции:**
- Встроенный таймер обратного отсчета для разминок
- Поддержка женской и мужской спортивной гимнастики
- Поддержка соревнований JO, FIG, NCAA
- Поддержка T&T (Trampoline & Tumbling) и RHY (Rhythmic)

**Коммуникация:**
- Система обмена сообщениями с главным судейским столом
- Требует ProScore v5.4.0+ для messaging
- Работает через WiFi сеть (интернет не нужен)

#### Технические требования

- **ОС:** iOS (iPad, iPhone)
- **Сеть:** WiFi (локальная сеть, не требуется интернет)
- **Совместимость:** ProScore, ProScoreTNT, ProScoreRHY v5.1.0+
- **Размер приложения:** ~50 MB

#### Процесс работы

1. Подключение iKeypad к WiFi сети
2. Соединение с ProScore на главном компьютере
3. Выбор снаряда/предмета
4. Ввод номера гимнастки
5. Ввод оценок судей
6. Отправка оценок на главный стол
7. Мгновенное отображение результатов

#### Преимущества

✓ Устраняет человеческие ошибки при переносе оценок
✓ Ускоряет процесс судейства
✓ Не требует интернета
✓ Бесплатное приложение
✓ Поддержка художественной гимнастики

#### Недостатки

✗ Только iOS (нет Android)
✗ Требует покупку ProScore лицензии
✗ Требует наличие iPad/iPhone

#### Лучшие практики использования

- Использовать iPad (не iPhone) для удобства судей
- Подготовить резервные устройства
- Тестировать WiFi перед соревнованиями
- Обучать судей заранее
- Использовать защитные чехлы для iPad

### 1.2 ScoreKing Scorepad

**Разработчик:** Carolina Kings Software LLC
**Платформы:** iOS, Android, Windows, Amazon Fire
**Стоимость:** Бесплатное приложение (требует ScoreKing server)
**Официальный сайт:** https://scoreking.com/

#### Описание

ScoreKing Scorepad — это приложение для судей, позволяющее вводить оценки для участников на каждом снаряде в соревнованиях по мужской и женской гимнастике.

**Конфигурация:**
- Настройка на 1, 2 или 4 судьи на снаряд
- 1 Scorepad на снаряд или 1 Scorepad на каждого судью
- Конфигурация vault для ввода лучших из 2 попыток или обеих

**Коммуникация:**
- Real-time сообщения от стола секретаря к Scorepad судей
- Передача информации, связанной с оценками

**Поддерживаемые организации:**
- USA Gymnastics (USAG)
- AAU
- NGA
- KCL
- PGL
- YMCA

#### Технические требования

- **Платформы:** iOS, Android, Windows, Amazon Fire
- **Сервер:** Требуется ScoreKing server software (лицензируется отдельно)
- **Сеть:** WiFi или локальная сеть
- **Регистрация:** scorekingcloud.com

#### Преимущества

✓ Кросс-платформенность (iOS, Android, Windows, Fire)
✓ Гибкая конфигурация
✓ Real-time messaging
✓ Поддержка Amazon Fire tablets (бюджетный вариант)

#### Недостатки

✗ Требует ScoreKing server лицензию
✗ Отдельная регистрация на scorekingcloud.com

## 3. Приложения для видеосудейства

### 3.1 Flyp10

**Разработчик:** Flyp10
**Платформы:** iOS, Android, Web
**Стоимость:** Pay-per-routine (малая плата за каждое выступление)
**Официальный сайт:** https://flyp10.com/sports/Wgymnastics

#### Описание

Платформа для загрузки видео выступлений и получения профессиональной оценки от сертифицированных USAG судей.

#### Ключевые возможности

**Видео Judging:**
- Загрузка видео с устройства или компьютера
- Выступления с соревнований, тренировок или открытых залов
- Оценка USAG Certified Judges соответствующего уровня
- Обязательные упражнения оцениваются на start value

**Требования к видео:**
- Относительно близкий ракурс
- Угол, позволяющий судейство
- Допустимы видео с соревнований, тренировок, open gym

**Аналитика:**
- Оценка и детали от сертифицированного судьи
- Библиотека достижений и highlights
- Sharing с тренерами, друзьями, семьей
- Analytics и отслеживание развития
- Сравнение с национальными трендами

**Premium подписка:**
- Priority routing (приоритетная обработка)
- Advanced analytics
- Соединение с college recruiters
- Участие в daily competitions

#### Технический процесс

1. Загрузка видео выступления
2. Добавление денег в wallet
3. Отправка на судейство
4. Сертифицированный судья оценивает
5. Получение оценки с детальными замечаниями
6. Сохранение в библиотеку

#### Ценообразование

- Плата за каждое оцененное выступление
- Зависит от ставок, которые Flyp10 платит судьям
- Для Irish Dancing: $8.00 (для гимнастики может отличаться)
- Pre-paid wallet система

#### Поддерживаемые виды спорта

- Women's Gymnastics (основной фокус)
- Men's Gymnastics
- Irish Dancing
- Другие виды спорта

#### Преимущества

✓ Профессиональное судейство от USAG Certified Judges
✓ Детальная обратная связь
✓ Видео с любого источника (соревнования, тренировки)
✓ Analytics и tracking
✓ Sharing возможности
✓ Доступно круглый год

#### Недостатки

✗ Платная услуга (за каждое выступление)
✗ Требует качественного видео
✗ Время обработки (не мгновенное)
✗ Основной фокус на спортивной гимнастике

#### Кейсы использования

- **Тренировки:** Получение feedback без поездок на соревнования
- **Подготовка:** Оценка готовности к соревнованиям
- **Улучшение:** Понимание конкретных дедукций
- **Рекрутинг:** Демонстрация навыков college coaches
- **COVID:** Альтернатива очным соревнованиям
