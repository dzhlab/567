## 1. Обзор рынка

### 1.1 Международные решения

Международный рынок ПО для художественной гимнастики представлен как крупными корпоративными системами, используемыми на официальных соревнованиях FIG, так и специализированными коммерческими продуктами для региональных и национальных мероприятий.

**Ключевые игроки:**
- **Swiss Timing** — официальный партнер FIG с более чем 30-летним опытом
- **RGScores** — специализированная платформа для художественной гимнастики
- **RG Form / KSIS** — европейская система регистрации и судейства
- **Elevien** — современная облачная платформа с поддержкой онлайн-соревнований
- **ProScore** — широко используемая в США система управления соревнованиями
- **Score Master** — традиционное решение с 35+ годами опыта
- **ScoreKing** — облачная система для соревнований любого масштаба
- **Kscore** — веб-платформа из Канады

### 1.2 Российские решения

Российский рынок представлен как официальными системами федераций, так и коммерческими разработками.

**Основные системы:**
- **Информационная система ФГР** (rg.gymnastics-base.ru) — интегрированная система Федерации гимнастики России
- **Sportvokrug** — распределенная судейская система для художественной гимнастики
- **Sporttech.io** — международная платформа с поддержкой российских соревнований с 2021 года

### 1.3 Open-source проекты

Open-source сообщество предлагает несколько проектов различной степени зрелости:

- **Rhythmic-Ranker** (GitHub: tristanqtn/Rhythmic-Ranker) — решение с AI-анализом для РГ
- **gymsystems** (GitHub: OysteinAmundsen/gymsystems) — полная веб-система для Team Gymnastic
- **gymscore** (GitHub: ccall48/gymscore) — веб-приложение для отображения результатов
- **agscore** (GitHub: Bnicke/agscore) — система для спортивной гимнастики на Elasticsearch

## 2. Детальный анализ программ

### Swiss Timing

**Разработчик:** Swiss Timing (часть Swatch Group)

**Официальный сайт:** https://www.swisstiming.com/sports/gymnastics/

**Целевая аудитория:** Международные федерации, олимпийские соревнования, чемпионаты мира

**Основной функционал:**
- Первичная и резервная системы судейства
- Быстрая и точная запись оценок судей
- Распределение результатов на табло и CIS (Commentator Information System)
- Поддержка всех дисциплин гимнастики: художественная, спортивная, прыжки на батуте, акробатика, аэробная гимнастика
- Touchscreen клавиатуры для судей
- IRCOS (Instant Replay and Communications System)
- Video Assist Judging System

**Поддерживаемые виды гимнастики:** Все виды (RG, AG, TRA, ACRO, AER)

**Платформы:** Специализированное hardware и software

**Модель распространения:** Коммерческая лицензия (цены не публикуются, контрактная основа для федераций)

**Технологический стек:**
- Специализированное hardware (судейские терминалы, табло)
- Проприетарное ПО
- Интеграция с FIG системами
- Real-time data distribution

**Интеграции:**
- Официальная интеграция с FIG
- Live timing & scoring веб-сервисы
- Интеграция с вещательными системами

**Преимущества:**
- Официальный статус FIG
- Высокая надежность (первичная и резервная системы)
- Проверенная репутация на крупнейших соревнованиях
- Полная техническая поддержка

**Недостатки:**
- Высокая стоимость
- Недоступна для небольших клубов и региональных соревнований
- Требует специализированного оборудования

### RGScores

**Разработчик:** RGScores (независимая разработка)

**Официальный сайт:** https://rgscores.com/

**Целевая аудитория:** Клубы и организаторы соревнований по художественной гимнастике

**Основной функционал:**
- Электронный ввод оценок судьями или традиционные карточки с централизованным вводом
- Live scoring для зрителей (app.rgscores.com)
- Автоматическая генерация рабочих заказов (work orders)
- Скачиваемые плейлисты музыки для каждой сессии
- Табло для отображения результатов и текущих участников
- Отслеживание сессий для тренеров
- Гибкая настройка правил
- Просмотр результатов по предметам и многоборью
- Отображение связок и итогов квалификации
- Детализация оценок

**Поддерживаемые виды гимнастики:** Художественная гимнастика (RG)

**Платформы:** Web-based

**Модель распространения:**
- Оплата за соревнование (1 кредит = 1 соревнование)
- Без платы за каждую заявку
- Без подписки
- Скидки для развивающихся стран и малых организаций

**Технологический стек:**
- Web-based платформа
- Cloud hosting
- Real-time updates
- Точные технологии не раскрываются

**Интеграции:** Онлайн просмотр результатов

**Преимущества:**
- Специализация на художественной гимнастике
- Простая ценовая модель
- Live scoring для зрителей
- Удобство для тренеров и организаторов
- Не требует установки ПО

**Недостатки:**
- Зависимость от интернета
- Ограниченная информация о технической поддержке
- Нет мобильных приложений для судей (только web)

**Модель распространения:**
- Бесплатная версия (freergform.rgvid.eu) для скриптинга

- Web-платформа
- Детали не раскрываются

**Интеграции:** Система регистрации и результатов

**Преимущества:**
- Бесплатный инструмент для создания форм сложности
- Поддержка офлайн-режима
- Европейская разработка с фокусом на FIG правила
- Удобный интерфейс для скриптинга

**Недостатки:**
- Ограниченная документация на английском
- Меньше известна за пределами Европы

## 4. Технологический ландшафт

### 4.1 Популярные технологии

#### Архитектурные подходы

**1. Cloud-native решения (тренд)**
- **Примеры:** RGScores, Elevien, ScoreKing, Kscore, Scoreholder, Sporttech.io
- **Преимущества:** Доступ из любой точки, автообновления, масштабируемость, live результаты
- **Недостатки:** Зависимость от интернета, проблемы конфиденциальности данных

**2. Desktop приложения (legacy)**
- **Примеры:** ProScore, Score Master
- **Технологии:** Windows Desktop (VB, .NET), MS Access
- **Преимущества:** Работа без интернета, контроль над данными
- **Недостатки:** Устаревшие технологии, сложность обновления, привязка к платформе

**3. Гибридные решения**
- **Примеры:** ScoreKing (облако + локальный сервер)
- **Преимущества:** Гибкость для разных условий
- **Недостатки:** Сложность поддержки двух режимов

**4. On-premise специализированные системы**
- **Примеры:** Swiss Timing, Kazo Vision, Sportvokrug
- **Преимущества:** Полный контроль, независимость от интернета, интеграция с hardware
- **Недостатки:** Высокая стоимость, сложность развертывания

#### Платформы и устройства

**Web-based (доминирующий тренд):**
- Браузерные приложения (HTML5, JavaScript frameworks)
- Responsive design для разных устройств
- Progressive Web Apps (PWA)

**Mobile:**
- iOS/Android нативные приложения (Elevien, ProScore iKeypad, ScoreKing apps)
- Кросс-платформенные фреймворки (React Native, Flutter - предполагается)

**Судейские устройства:**
- Планшеты (iPad, Android tablets, Fire tablets)
- Специализированные touchscreen терминалы (Swiss Timing)
- Handheld устройства (Kazo Vision)

#### Базы данных

**Используемые технологии:**
- **MS Access** (Score Master) - legacy
- **Централизованные SQL/NoSQL** (предполагается для облачных решений)
- **Elasticsearch** (agscore) - для поиска и аналитики
- **Cloud databases** (предполагается: AWS RDS, Google Cloud SQL, Firebase)

#### Frontend технологии

**Предполагаемые стеки (на основе современных веб-приложений):**
- React, Vue.js, Angular для SPA
- Bootstrap, Tailwind CSS для UI
- Real-time libraries (Socket.io, WebSockets)

#### Backend технологии

**Предполагаемые (industry standard):**
- Node.js, Python (Django/Flask), Ruby on Rails
- .NET Core для Windows-based решений
- Microservices архитектура для крупных платформ

### 4.2 Стандарты и протоколы

#### FIG Standards

**Code of Points (CoP):**
- Основной стандарт для правил судейства
- Обновляется каждый олимпийский цикл (текущий: 2025-2028)
- Все профессиональные системы должны его поддерживать

**FIG Technical Regulations:**
- Технические требования к соревнованиям
- Требования к аккредитации
- Apparatus Norms (стандарты оборудования)

**FIG Database Platform:**
- Онлайн-система регистрации
- Биографические данные участников
- Управляется национальными федерациями

#### Национальные стандарты

**USA Gymnastics (USAG):**
- Интеграция с meet reservation system
- myusagym.com для live результатов
- NCAA правила для университетской гимнастики
- Системы с интеграцией: ProScore, Score Master, ScoreKing, Kscore

**UEG (European Gymnastics):**
- Европейские правила и регламенты
- Интеграция с Elevien, Sporttech.io

**Российская Федерация:**
- Правила вида спорта "Художественная гимнастика"
- Единая информационная система ФГР
- Квалификационные требования к судьям

#### Форматы данных

**Экспорт результатов:**
- PDF (универсальный формат для отчетов)
- CSV/Excel (для аналитики)
- XML/JSON (для API интеграций)
- Проприетарные форматы для обмена между системами

**Видео:**
- MP4 для видеоповтора (Sportvokrug, Elevien)
- Streaming протоколы для live трансляций

#### API и интеграции

**Отсутствие публичных API:**
- Большинство систем не предоставляют публичные API
- Интеграции делаются на контрактной основе
- Закрытые экосистемы

**Типичные интеграции:**
- Системы регистрации → Судейские системы
- Судейские системы → Табло
- Результаты → Веб-сайты федераций
- Результаты → Мобильные приложения для зрителей

- Вес системы: промышленный стандарт

**Другие системы:**
- **Планшеты:** iPad (ProScore iKeypad), Android tablets, Amazon Fire tablets (ScoreKing)
- **Ноутбуки:** Windows/Mac для централизованного ввода
- **Смартфоны:** для некоторых cloud-решений (Scoreholder, Elevien)

#### Табло и дисплеи

**Профессиональные табло:**
- LED scoreboards (Swiss Timing, Score Master с EliteScore)
- Интеграция с системами судейства
- Отображение текущих оценок, лидеров, расписания

**Бюджетные решения:**
- TV экраны с web-браузером
- Amazon Fire TV Stick (ScoreKing)
- Проекторы с компьютером

#### Серверное оборудование

**On-premise системы:**
- Windows/Linux серверы
- Локальная сеть для судейских терминалов
- Видеооборудование (камеры, видеомикшеры) для систем с повтором

**Sportvokrug специфика:**
- 100 кг оборудования
- 6 часов на развертывание (2 человека)

**Cloud системы:**
- Не требуют локального серверного оборудования
- Зависимость от качества интернета (рекомендуется >10 Mbps)

#### Сетевое оборудование

**Требования:**
- WiFi для планшетов и мобильных устройств судей
- Ethernet для стабильности (критичные компоненты)
- Backup интернет-канал для cloud-систем
- Локальная сеть для on-premise решений

### 4.4 Тренды и перспективы

#### 1. Искусственный интеллект и машинное обучение

**Fujitsu Judging Support System (JSS):**
- AI-powered анализ движений гимнастов
- 3D-моделирование на основе камер высокого разрешения
- Real-time измерение скоростей, углов, скелетных позиций
- Deep learning workstations с NVIDIA GPU
- Использовалось на Olympics 2024 Paris
- **Статус:** Production-ready для спортивной гимнастики (10 снарядов)

**Computer Vision:**
- Анализ формы и выступлений в реальном времени
- Автоматическое определение элементов
- Выявление рисков травм по паттернам движений
- Персонализированная обратная связь для спортсменов и тренеров

**Rhythmic-Ranker (open-source):**
- Экспериментальный AI для художественной гимнастики
- Объективная оценка на основе измеримых критериев
- **Статус:** Экспериментальный

**Перспективы:**
- Расширение AI-систем на художественную гимнастику
- Помощь судьям (не замена) в реальном времени

## 5. Рекомендации

### 5.1 Для небольших клубов

**Бюджетные решения:**

**Первый выбор: Elevien**
- **Почему:** Бесплатно, современный интерфейс, мобильные приложения, простота использования
- **Подходит для:** Внутриклубных соревнований, тренировочных сборов, малых турниров
- **Ограничения:** Неясна долгосрочная бизнес-модель, может стать платной

**Альтернатива: RGScores**
- **Почему:** Специализация на художественной гимнастике, оплата за соревнование (без подписки)
- **Подходит для:** Региональных турниров, клубных чемпионатов
- **Плюсы:** Live scoring, не требует технических навыков

**Для скриптинга форм D:**
- **RG Form (бесплатная версия)** — специализированный инструмент для создания форм сложности

**Open-source опция (для технически подкованных):**
- **gymscore** — если есть разработчик в команде
- **Требования:** Хостинг, техническая поддержка
- **Плюсы:** Полный контроль, нет лицензионных затрат
- **Минусы:** Требует технических навыков

**Рекомендуемая конфигурация:**
- 2-3 планшета (iPad или Android) для судейских столов
- 1 ноутбук для координатора
- TV или проектор для табло
- Стабильный WiFi

---

### 5.2 Для региональных федераций

**Оптимальный выбор: RGScores или Scoreholder**

**RGScores:**
- **Преимущества:**
  - Специализация на RG
  - Простая ценовая модель (за соревнование)
  - Live результаты для зрителей
  - Не требует технической инфраструктуры
- **Подходит для:** 10-50 соревнований в год
- **Ориентировочная стоимость:** Низкая-средняя (1 кредит на соревнование)

**Scoreholder:**
- **Преимущества:**
  - Универсальность (разные виды спорта)
  - Облачное хранение
  - Генерация документов и сертификатов
  - Табло и онлайн-публикация
- **Подходит для:** Федераций с несколькими видами спорта

**Для России: Sportvokrug**
- **Преимущества:**
  - Русскоязычная система
  - Видеоповтор
  - Специализация на РГ
  - Real-time контроль
- **Недостатки:**
  - Требует значительного оборудования
  - Сложное развертывание
- **Подходит для:** Региональных и национальных чемпионатов в РФ

**Альтернатива: ScoreKing**
- **Преимущества:**
  - Гибкость (облако или локальный сервер)
  - Масштабируемость
  - Поддержка разных устройств
- **Недостатки:** Меньший фокус на художественной гимнастике

**Рекомендуемая инфраструктура:**
- 5-10 планшетов для судей
- 1-2 ноутбука для секретариата
- Профессиональное LED табло или несколько TV
- Backup интернет-канал
- Видеосистема (опционально, для важных соревнований)

### 5.3 Для национального уровня

**Tier 1: Официальные и крупные системы**

**Swiss Timing**
- **Для:** Чемпионаты мира, международные турниры под эгидой FIG
- **Преимущества:**
  - Официальный статус FIG
  - Максимальная надежность
  - Полная техподдержка
  - Интеграция с вещанием
- **Недостатки:**
  - Очень высокая стоимость
  - Контрактная модель
- **Когда выбирать:** При проведении FIG-сертифицированных соревнований

**Sporttech.io**
- **Для:** Национальных и международных чемпионатов
- **Преимущества:**
  - FIG-совместимость
  - Real-time онлайн-доступ
  - Поддержка всех дисциплин
  - Современная платформа
- **Когда выбирать:** Для национальных федераций с активным международным календарем

**Tier 2: Специализированные национальные решения**

**Для России: Информационная система ФГР**
- **Преимущества:**
  - Официальная государственная система
  - Интеграция с судейскими системами
  - Централизованные реестры
  - Бесплатно для участников
- **Обязательно для:** Официальных всероссийских соревнований

**Дополнительно для РФ: Sportvokrug**
- Для соревнований, требующих видеоповтора и расширенного функционала

**Для США: ProScore или Score Master**
- **Преимущества:**
  - USAG/NCAA интеграция
  - Проверенные системы
  - Широкое распространение в США
- **Недостатки:**
  - Desktop-приложения
  - Устаревающие технологии (особенно Score Master)

**Tier 3: Современные облачные альтернативы**

**RGScores + Elevien (гибрид)**
- RGScores для основных соревнований
- Elevien для экспериментальных онлайн-форматов и отборочных туров

**Рекомендуемая стратегия:**

1. **Основная система:** Swiss Timing или Sporttech.io для топовых международных мероприятий

2. **Национальные соревнования:**
   - РФ: ФГР + Sportvokrug
   - США: ProScore/Score Master
   - Другие: RGScores, Sporttech.io, Scoreholder

3. **Региональные отборы:** RGScores, Elevien

4. **Инновации:** Пилотирование Elevien для онлайн-форматов, мониторинг развития AI-систем (Fujitsu JSS для RG)

**Инфраструктура:**
- Профессиональные судейские терминалы или планшеты (15-20 шт)
- Серверное оборудование (on-premise или cloud)
- Профессиональные LED табло
- Многокамерная видеосистема с повтором
- Резервный канал интернета
- Техническая команда на месте
- Интеграция с национальной базой данных

## Заключение

Рынок программного обеспечения для соревнований по художественной гимнастике демонстрирует активное развитие с четким трендом на облачные, мобильные и AI-powered решения.

**Ключевые выводы:**

1. **Доминирование облачных решений:** Большинство современных систем переходят на cloud-based архитектуру

2. **Специализация vs универсальность:** Существуют как специализированные РГ-системы (RGScores, RG Form), так и универсальные платформы

3. **Географическая фрагментация:** Разные регионы имеют свои предпочтительные системы (США - ProScore/Score Master, Россия - ФГР/Sportvokrug, Европа - RG Form/Elevien)

4. **AI - будущее судейства:** Fujitsu JSS демонстрирует потенциал AI в объективизации оценок, но пока только для спортивной гимнастики

5. **Онлайн-соревнования:** Формат, ускоренный пандемией, становится стандартным для отборочных туров

6. **Отсутствие открытых стандартов:** Большинство систем - закрытые экосистемы без публичных API

7. **Ценовой разброс:** От бесплатных (Elevien, open-source) до очень дорогих (Swiss Timing) решений

**Возможности для инноваций:**
- Open-source специализированная система для РГ
- AI для художественной гимнастики
- Стандартизированные API и форматы данных
- Blockchain для прозрачности судейства

Выбор системы должен базироваться на уровне соревнований, бюджете, технических возможностях и географии проведения мероприятий.
